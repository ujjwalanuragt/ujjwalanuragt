  <br />
  A fully functional UNIX shell built from scratch, handling core terminal tasks like process execution, directory navigation, and environment variable management.

  | Tech Stack | Repository |
  | :--- | :--- |
  | C, POSIX API, Linux System Calls | [View Code](https://github.com/ujjwalanuragt/My_Custom_Shell) |
